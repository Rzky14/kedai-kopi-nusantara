# Kedai Kopi Nusantara ☕

Website kedai kopi premium dengan desain modern dan profesional. Dibuat menggunakan HTML, CSS, dan JavaScript murni dengan animasi yang smooth dan responsif.

## ✨ Fitur

- 🎨 **Desain Premium** - Tampilan modern dengan typography profesional (Playfair Display & Poppins)
- 📱 **Fully Responsive** - Tampil sempurna di semua perangkat
- ⚡ **Animasi Smooth** - Menggunakan AOS library untuk scroll animations
- 🎯 **Interactive Menu** - Menu tabs dengan kategori (Kopi, Non-Kopi, Makanan)
- 📸 **Gallery Modal** - Galeri foto dengan lightbox effect
- 💬 **Testimonials** - Section review pelanggan
- 📮 **Contact Form** - Form kontak yang interaktif
- 🔝 **Scroll to Top** - Button untuk kembali ke atas
- 🎭 **Parallax Effects** - Efek parallax pada hero section
- 📊 **Animated Stats** - Counter animasi untuk statistik

## 📋 Halaman

1. **Beranda** - Hero section dengan CTA dan statistik
2. **Tentang** - Informasi tentang kedai kopi
3. **Menu** - Daftar menu dengan kategori
4. **Galeri** - Foto-foto kedai dan produk
5. **Testimoni** - Review dari pelanggan
6. **Kontak** - Informasi kontak dan form

## 🛠️ Teknologi

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox, Animations)
- JavaScript (ES6+)
- Font Awesome Icons
- Google Fonts (Playfair Display, Poppins)
- AOS (Animate On Scroll)

## 📦 Instalasi

1. Clone repository ini:
```bash
git clone https://github.com/Rzky14/kedai-kopi-nusantara.git
```

2. Buka folder project:
```bash
cd kedai-kopi-nusantara
```

3. Buka file `index.html` di browser atau gunakan Live Server di VS Code

## 📁 Struktur File

```
kedai-kopi-nusantara/
```
